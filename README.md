## Resmî kaynaklar

- **[USOM](https://www.usom.gov.tr)** — Ulusal Siber Olaylara Müdahale Merkezi. Zafiyet bildirimleri, tehdit bültenleri ve olay müdahale rehberleri.
- **[Siber Güvenlik Başkanlığı](https://siberguvenlik.gov.tr)** — Ulusal siber güvenlik politikaları, farkındalık ve koordinasyon.
- **[BTK Akademi](https://www.btkakademi.gov.tr)** — Ücretsiz siber güvenlik ve ağ eğitimleri (Türkçe).
- **[Hacktrick](https://hacktrickconf.com)** — Türkiye'nin öğrenci odaklı siber güvenlik konferansı; eğitimler ve CTF.

## Öğrenme platformları

- **[PortSwigger Web Security Academy](https://portswigger.net/web-security)** — Ücretsiz, laboratuvar destekli web güvenliği eğitimi. Başlangıç için en iyi kaynak.
- **[TryHackMe](https://tryhackme.com)** — Rehberli, tarayıcıdan erişilebilen lab'lar.
- **[Hack The Box](https://www.hackthebox.com)** — Daha ileri seviye makineler ve Academy.
- **[OWASP WSTG](https://owasp.org/www-project-web-security-testing-guide/)** — Web uygulaması test metodolojisi.
- **[OWASP Cheat Sheet Series](https://github.com/OWASP/CheatSheetSeries)** — Uygulama güvenliği için kısa, uygulanabilir rehberler.

## Web güvenliği araçları

- **[Burp Suite Community](https://portswigger.net/burp/communitydownload)** — Trafik yakalama ve manuel test için temel araç.
- **[OWASP ZAP](https://www.zaproxy.org)** — Açık kaynak, otomatik tarama + proxy.
- **[nuclei](https://github.com/projectdiscovery/nuclei)** — Şablon tabanlı zafiyet taraması.
- **[ffuf](https://github.com/ffuf/ffuf)** — Hızlı içerik/parametre keşfi.
- **[httpx](https://github.com/projectdiscovery/httpx)** — HTTP parmak izi ve toplu prob.
- **[subfinder](https://github.com/projectdiscovery/subfinder)** — Pasif alt alan adı keşfi.
- **[sqlmap](https://github.com/sqlmapproject/sqlmap)** — SQL enjeksiyonu tespit ve doğrulama.
- **[Nmap](https://nmap.org)** — Port ve servis taraması.
- **[Kali Linux](https://www.kali.org)** — Hazır güvenlik dağıtımı.

## Kod ve bağımlılık güvenliği

- **[gitleaks](https://github.com/gitleaks/gitleaks)** — Git geçmişinde sır/anahtar taraması.
- **[Semgrep](https://github.com/semgrep/semgrep)** — Hafif, kural tabanlı statik analiz.
- **[Trivy](https://github.com/aquasecurity/trivy)** — Konteyner, dosya sistemi ve IaC zafiyet taraması.

## Katkı

Yeni kaynak önerirken:

1. Link çalışıyor olmalı.
2. Kaynak aktif bakımda olmalı (son 12 ay içinde güncelleme).
3. Türkçe içerik veya Türkiye'den topluluk/araç önceliklidir.
4. Reklam, affiliate veya ücretli yönlendirme kabul edilmez.
